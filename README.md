# Observatório de Políticas Públicas no Território

Observatório Territorial de Políticas Públicas desenvolvido para integrar, analisar e visualizar indicadores socioeconômicos, habitacionais e de infraestrutura urbana de forma interativa, facilitando a leitura territorial, a comparação entre municípios e o apoio à tomada de decisão em políticas públicas.
